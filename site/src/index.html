Go A hands-on course

Learn Go by building a bandit service

One project, fourteen chapters. It starts as a command-line simulation of a multi-armed bandit and grows into replicated gRPC microservices, picking up the language and the backend patterns exactly when the project needs them.

How the course works

A multi-armed bandit repeatedly chooses one of several options (an ad, a model variant, a ranking), observes a reward, and has to balance trying things it is unsure about against repeating what already works. That decision loop is small enough to fit in a few hundred lines and rich enough to need everything a Go backend uses: interfaces, testing, concurrency, HTTP, persistence, metrics, and finally state that has to stay consistent across replicas.

  • Every listing is real. Code on these pages is pulled from solutions/chNN, which compiles and passes go test -race. Terminal output comes from running it, with fixed seeds.
  • Each chapter is a complete snapshot. cd solutions/ch05 && go test -race ./... works without anything else. Lines a chapter adds are marked in the margin of its listings.
  • Exercises have tests. Each chapter ships starters in exercises/chNN that fail until you implement them; reference answers sit under a fold on the page.

You need Go 1.24 or newer. Start with , or read the README for how to run any chapter.
